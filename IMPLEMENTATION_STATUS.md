## Key Implemented Capabilities

1. **Markdown-First Source of Truth:** All notes live directly as `.md` files under `${CORTEX_DATA_DIR}/vaults/<slug>/` with standard YAML frontmatter, `[[WikiLinks]]`, `![[Note]]` transclusion, `cortex-query` live blocks, JSON Canvas `.canvas` boards, tags, and `/assets/` binary attachments.
2. **Real-Time Multi-Device Sync, Git Snapshots & Offline PWA:** Server-Sent Events (`/api/events`), SHA-256 optimistic concurrency conflict detection (`409 CONFLICT` + 3-way hunk-by-hunk merge modal), snapshot versioning (`note_versions`), per-vault Git commits (`/api/workspaces/[slug]/git`), Service Worker + IndexedDB (`cortexmd_offline_v1`) offline caching/search (`src/lib/offline-db.ts`), and PWA Web Share Target + bearer-token webhook quick capture (`/api/capture`).
3. **Grounded AI Studio without Mandatory Paid API Keys:** Built-in `local-hybrid` SQLite FTS5 + 384-dim semantic RAG with SSE streaming (`/api/ai/chat`), line-range citations (`#Lstart-Lend`), hover citation previews, inline `Ctrl+I` diff rewrites (`/api/ai/rewrite`), URL/HTML web clipping (`/api/ai/ingest` with SSRF blocking), Study Guide / FAQ / Two-Host Audio Briefing with Web Speech API TTS (`/api/ai/briefing`), and approval-gated Vault Gardener (`/api/ai/gardener`) & agent diffs (`ai_pending_actions`) filtered strictly through `ai_folder_permissions` ACLs.
4. **Graph Intelligence, Active Recall & Multi-User RBAC:** Shortest-path BFS (`findShortestNotePath`), dashed semantic ghost edges & community clusters (`KnowledgeGraph.tsx`), SM-2 active-recall flashcards (`/api/flashcards`, `FlashcardReviewView.tsx`), Saved Smart Searches (`/api/search/saved`), and multi-user accounts with per-workspace `admin`/`editor`/`viewer` role enforcement (`workspace_members`, `requireWorkspaceRole`, `/api/users`).
